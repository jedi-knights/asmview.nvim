==============================================================================
1. INTRO                                                        *asmview-intro*

asmview.nvim compiles the function surrounding the cursor (or an explicit
range) to assembly and displays the result in a floating window. Supports
C, C++, and Rust.

==============================================================================
2. REQUIREMENTS                                          *asmview-requirements*

- Neovim >= 0.10
- One of `cc`, `c++`, `rustc` on $PATH, depending on the language
- Optional: `c++filt`, `rustfilt` for symbol demangling
- Optional: a `compile_commands.json` for C/C++ project flags

==============================================================================
3. SETUP                                                        *asmview-setup*

                                                            *asmview.setup()*
require("asmview").setup({opts})

{opts} is a table matching |asmview-config|. Omitted fields fall back to the
documented defaults. Calling setup() multiple times is safe; the last call
wins.

==============================================================================
4. COMMANDS                                                  *asmview-commands*

                                                                  *:Asm*
:[range]Asm
    Compile and show assembly. With no range, uses the function enclosing the
    cursor. With `:'<,'>Asm` or any explicit range of 2+ lines, uses those
    lines verbatim.

==============================================================================
5. MAPPINGS                                                  *asmview-mappings*

                                                       *<Plug>(AsmView)*
<Plug>(AsmView)
    In normal mode, run against the function at the cursor. In visual mode,
    run against the selection. asmview does not auto-bind this; map it in
    your config:
>
    vim.keymap.set({ "n", "x" }, "<leader>a", "<Plug>(AsmView)")
<

==============================================================================
6. WINDOW KEYS                                            *asmview-window-keys*

Buffer-local maps inside the asm window (customize via `keymaps` in setup):

  `+`   increase optimization level (clamped at the end of `opt_levels`)
  `-`   decrease optimization level
  `R`   rerun the compiler with the current parameters
  `q`   close the window

==============================================================================
7. CONFIGURATION                                              *asmview-config*

Defaults: >

    {
      compilers = {
        c   = { cmd = "cc",    extra_args = {} },
        cpp = { cmd = "c++",   extra_args = {} },
        rust = { cmd = "rustc", extra_args = {} },
      },
      opt_levels = { "0", "1", "2", "3", "s", "z" },
      default_opt = "2",
      syntax = "intel",
      demangle = true,
      use_compile_commands = true,
      compile_commands_search_depth = 6,
      float = {
        width_ratio = 0.8,
        height_ratio = 0.8,
        border = "rounded",
      },
      keymaps = {
        increase_opt = "+",
        decrease_opt = "-",
        rerun = "R",
        close = "q",
      },
    }
<

==============================================================================
8. compile_commands.json                            *asmview-compile-commands*

For C and C++ sources only, asmview walks up from the source file (capped at
`compile_commands_search_depth` hops) looking for `compile_commands.json`. If
found, it uses the matching entry's flags, stripping `argv[0]`, `-c`, `-S`,
any `-O*`, `-o <path>`, and the input file itself. The remaining flags are
appended before `-S` and the input file.

==============================================================================
9. HEALTH                                                      *asmview-health*

                                                       *:checkhealth-asmview*
:checkhealth asmview
    Reports the status of each configured compiler, optional demanglers, and
    treesitter availability.
